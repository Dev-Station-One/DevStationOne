# Journal

A running log of notes about the project — decisions made, context for the
next person (or your future self), incidents, anything worth remembering
that doesn't belong in a commit message.

- **New note** opens a rich-text editor; notes are timestamped and credited
  to the display name set on your [Account](/help.html#account) page.
- The table shows a snippet, timestamp, and author for each note; click a
  row to read the full note.
- **Refresh** re-reads notes — useful if a teammate just added one.
- Long journals page with **Prev**/**Next**.

Notes are shared with anyone who has access to the project — treat this as
a team log, not a private scratchpad.
