# Dashboard

The Dashboard is a live-updating summary, not a management screen.

The two lists live in one card behind a tab selector — **Projects** is the
default tab, **Runtimes** is one click away:

- **Projects** lists your projects with their runtime and current session
  count. Click a row to open that project's workspace.
- **Runtimes** shows only *online* Development Runtimes. Offline, pending,
  and revoked runtimes stay on the full [Runtimes](/help.html#runtimes) page
  so this view doesn't clutter with things you can't act on right now.

The lists refresh automatically over the shared event stream — no need to
reload the page after starting a runtime or creating a project, even if the
other tab is not the one you are looking at.

To create your first project, go to [Projects](/help.html#projects) and
register a [Runtime](/help.html#runtimes) first if you haven't already.
